Lab 6 – Training and Comparing Regression Models (Airbnb Dataset): This Jupyter notebook trains multiple regression models to predict Airbnb listing prices and compares their performance using industry-standard metrics such as RMSE and R². The lab demonstrates model training, hyperparameter tuning, ensemble methods, and performance visualization.

🎯 Objective
- Build and evaluate several regression models to determine which method best predicts Airbnb listing prices based on a dataset of preprocessed features.
- Source: airbnbData_train.csv (located in data_LR folder)
- Target Variable (Label): price (continuous numerical value)
- Features: All remaining columns (preprocessed with one-hot encoding, scaling, and imputations already applied)
