Lab 5 – Machine Learning Lifecycle: Evaluation and Deployment: This lab focuses on the final stages of the machine learning lifecycle: evaluating model performance and preparing a model for deployment. Using the Airbnb NYC listings dataset, you build on previous labs by transitioning from model training to performance assessment and real-world application readiness.

🎯 Objectives
- Evaluate trained machine learning models using appropriate metrics
- Interpret performance results in the context of business goals
- Simulate the deployment phase of a machine learning pipeline
- Understand the practical implications of deploying a predictive model

📊 Dataset
- Dataset: Airbnb NYC Listings
- Target Variable: price
- Features: Preprocessed (encoded, scaled, and cleaned) features representing listing characteristics
